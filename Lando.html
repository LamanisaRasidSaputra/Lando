Spreadsheet: ABSEN KELAS 11 Lando. Langkah ini hanya sekali per perangkat.

  1. Di spreadsheet: Extensions → Apps Script, tempel Code.gs, simpan, lalu Run tesKoneksi dan klik Allow.
  2. Deploy → New deployment → Web app. Execute as: Me. Who has access: Anyone. Klik Deploy.
  3. Salin URL yang berakhiran /exec (bisa dilihat lagi dari menu spreadsheet Absensi QR → Tampilkan URL Web App).
  4. Tempel di bawah, lalu tekan tombol kuning.
